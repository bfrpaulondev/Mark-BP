# Daily Report
## Objectivo: ajudar a preencher o relatório diário com o trabalho real do dia.
## Triggers: "relatório diário" / "daily report"
## Quando NÃO usar: sem dados do utilizador (nunca inventar trabalho).
## Regras: preview sempre primeiro; submissão só com confirmação explícita.
## Success criteria: relatório formatado com secções preenchidas a partir dos argumentos.
## Failure/recovery: sem dados → devolve relatório vazio com aviso.
## Permissions: nenhuma.
